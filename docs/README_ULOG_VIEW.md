# kart_log_view 用法（本工程 ULog43）

## 打开哪个文件
- 打开新版 HTML：`kart_log_view_mecanum_v4.html`（本地离线，无需网络）
- 四轮独看、场地配准、波形缩放和数据解释见 `viewer/README.md`。
- 优先拖入：`E:/LOG1/log1.csv` / `E:/LOG1/log0.csv`
- 旧转换文件也可用：`log0_kart.csv`

不要拖 `*_oldformat_*.txt`（旧 26 列带表头）。
新固件日志即使原来是 .txt，内容也是 43 列 CSV；现已把记录仪后缀改为 `.csv`。

## 烧录后新日志
记录仪 `param_config.txt` 关键配置：
- `#filehead:LOG1/log`
- `#filename:csv`
- `#filenew:1`

上电录音后，新文件在 `LOG1/logN.csv`，可直接丢进同一个 HTML。

## 通道对应（查看器关键项）
| 查看器 | 通道 | 本车数据 |
|---|---|---|
| phase | 1 | 0等待 / 1直行 / 2转弯 / 3等待动作 / 4结束 |
| 比赛状态 | 2 | RaceState：0准备 / 1运行 / 2完成 / 3故障 / 4中止 |
| 路线/错误/任务 | 3/6/7/9 | 动作索引、错误码、任务索引、任务队列完成标志 |
| 实测车体速度 | 10/11 | vx/vy，车体系 m/s；网站优先使用这两个通道 |
| 目标车体速度 | 12/13 | vx/vy，车体系 m/s |
| yaw | 16 | 底盘航向 deg |
| yawu | 17 | IMU航向 deg |
| 平移目标速度大小 | 19 | 乘 0.073632 得 m/s；无方向，不能作为 vx |
| 轮速绝对值均值 | 20 | 乘 0.073632；不是底盘平移速度，不能作为 vx |
| 四轮实测 | 28/29/30/31 | FL/FR/RL/RR，pulse/s；新版据此计算带方向的 vx、vy、ω |
| 控制输出 / 累计编码器 | 未记录 | 43 列中暂未占用；网站显示“未记录” |
| 四轮目标速度 | 27/35/36/37 | FL/FR/RL/RR，pulse/s；ch38 为四轮最大绝对控制输出 |
| 电源电压 | 40/41 | 驱动器 VIN / 主控 VIN，V |
| 目标/实测角速度 | 14/15 | rad/s；旧转换文件 ch15 可能是占位零 |
| ox/oy | 32/33 | x/y 位置 m |
| odo | 34 | 累计路程 m |
| elat | 39 | 横向误差 m |
| herr | 42 | 航向误差 deg |

额外：ch4=底盘到达标记，ch5=ms，ch18=目标角速度 deg/s，ch21/22/23=目标位姿，ch24/25/26=ex/ey/eyaw；比赛模式 ch2/ch3/ch6/ch7/ch9 按上表解释。

## 底盘调试版升级

新版 `kart_log_view_mecanum_v4.html` 已增加：转换日志来源识别、数据质量页、时间间隔统计、异常行提示、运动分段联动、目标轨迹、停车响应估计和本机分析配置保存。详见 `viewer/README.md`。

轨迹页默认显示右下角波形小窗，点击“展开波形”查看完整工具，“收起波形”返回小窗；无需切换浮动布局。

## 比赛模式与停录（2026-11-05）

比赛模式已接入 USART2 日志，当前独立夹取测试在动作及复位结束后锁定停录；正常模式等待当前已实现流程及夹取停止，旧正方形模式在完成/超时/中止后停录。完整比赛后续动作尚未接通，不能把到原料区的 RACE_DONE 当整场比赛完成。

比赛日志 ch2/ch3 是 RaceState/路线索引，ch6 为路线错误、ch7 为任务队列索引、ch9 为整队列完成标志；旧查看器的 sq_st/sq_step 标签需按此解释。停录后须复位主控才重新记录。

停止串口发送不代表 TF 文件已经关闭。详细停录条件、测试方法和记录仪落盘限制见 `sd_logger/README_SD_LOGGER.md`。

轨迹页波形小窗支持点击 `⌁` 图标最小化为圆形图标，再次点击图标恢复波形。
