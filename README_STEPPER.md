# D36A 双路步进开环驱动（基于官方用户手册 V1.5）

资料来源：`【WHEELTEC】D36A步进电机驱动附送资料_V1.1_2026.04.20`

## 1. 官方控制方式（不是串口从站）

D36A 用户手册明确：每路电机用 **3 根控制线**：

| 信号 | 作用 |
|---|---|
| **ST** | STEP，**上升沿有效**，每来一个上升沿走 1 个细分步（需 PWM/脉冲方波） |
| **DIR** | 方向，高低电平 |
| **EN** | 高电平使能，低电平休眠 |

D36A **没有** UART/Modbus 通讯协议。  
串口是给 **STM32** 发指令用的；STM32 再产生 ST/DIR/EN 去驱动 D36A。

```
上位机 --USART3--> STM32(GongChuangSai) --ST/DIR/EN--> D36A --> 两路42步进
```

## 2. 本工程 C30D 引脚（已查冲突）

| D36A | MCU | 说明 | 与麦轮冲突？ |
|---|---|---|---|
| ST1 | PC6 (TIM8_CH1) | C30D 航模/舵机排针 | 仅与同排针舵机互斥 |
| DIR1 | PC8 (GPIO) | 原 TIM8_CH3，现改 GPIO | 同上 |
| EN1 | PA2 (GPIO) | H2 预留 IO 第 12 脚 | 无 |
| ST2 | PC7 (TIM8_CH2) | 舵机排针 | 仅与同排针舵机互斥 |
| DIR2 | PC9 (GPIO) | 原 TIM8_CH4，现改 GPIO | 同上 |
| EN2 | PA3 (GPIO) | H2 预留 IO 第 10 脚 | 无 |
| 电压检测 | PC0 (ADC1_IN10) | H2 预留 IO 第 15 脚 | 读 VIN/11 |
| GND | GND | 必须共地 | - |
| VIN | 外部 12V | 电机电源 | - |

麦轮电机（TIM1/9/10/11 + 编码器）完全不动。  
USART3（PD8/PD9，C30D USB串口3）做指令口。


## 2.1 接线要点（原理图核对）

- ST1/DIR1/ST2/DIR2 全部来自 **6 路舵机排针**：J1=PC6、J2=PC7、J4=PC8、J5=PC9，
  三针排列为 **1=信号 / 2=5V / 3=GND**，信号取第 1 脚，地取第 3 脚。
- EN1/EN2 从 **H2 预留 IO 排针**（HX PZ2.54-2X10P）取：**第 12 脚 = PA2、第 10 脚 = PA3**。
- 该排针第 20 脚是 3V3、第 18 脚是 GND，可取来给 EN 做常使能（不占用 MCU 时）。
- D36A 的 VIN 接 **外部 12V**（J3 12V 输入或电池），GND 必须与主控板共地。


## 2.2 电源电压检测（两路 VIN/11）

| 通道 | 引脚 | 位置 | 说明 |
|---|---|---|---|
| 驱动器侧 VB | **PC0**（ADC1_IN10） | H2 第 15 脚 | D36A 的电源检测输出 = VIN/11 |
| 主板侧 VM | **PB0**（ADC1_IN8） | 板上自带分压 | R27=100k / R26=10k，也是 1/11 |

D36A 的输出：12V -> 1.09V，24V -> 2.18V，都在 3.3V 量程内。

```c
Vbat_Init();                        /* PC0/PB0 模拟输入 + ADC1 校准 */
Vbat_Poll();                        /* 主循环调用，内部 100ms 节流 */
float vb = Vbat_GetDriverVoltage(); /* 驱动器侧 VIN */
float vm = Vbat_GetBoardVoltage();  /* 主板侧 VIN */
```

OLED 第 4 页第三行显示 `VB12.63 VM12.71`，未接的通道显示 `--.--`。

换算：`VIN = raw / 4095 * 3.3 * 11`；实测偏差大时改 `bsp_vbat.h` 里的
`VBAT_VREF`（万用表量 VDDA）或 `VBAT_DIVIDER_RATIO`。

## 2.3 步进驱动模块（转速 / 加减速 / 转圈数）

`Hardware/app_stepper_drive.c` 是专门驱动 42 步进电机的模块，
**只管 A/B 两个步进轴，不涉及麦轮底盘**。

### 单位换算

```
脉冲/圈   = 200（1.8°电机）× 细分（拨码 123，默认 16） = 3200
脉冲频率  = rpm / 60 × 脉冲每圈        例：30rpm -> 1600Hz
每圈时间  = 60 / rpm                   例：30rpm -> 2 秒/圈
```

### 常用接口

```c
StepperDrive_Init();                                   /* 初始化 */

StepperDrive_MoveRevs(0, +1, 1.0f, 30.0f, 120.0f);     /* A 轴正转 1 圈 */
StepperDrive_MoveRevs(0, -1, 2.0f, 60.0f, 240.0f);     /* A 轴反转 2 圈，60rpm */
StepperDrive_MoveSteps(0, +1, 3200, 30.0f, 120.0f);    /* 指定脉冲数 */
StepperDrive_Spin(0, +1, 30.0f, 120.0f);               /* 连续转 */
StepperDrive_Stop(0);                                  /* 停 */

StepperDrive_Poll();                                   /* 主循环里必须持续调用 */
```

参数顺序：`轴号(0=A,1=B), 方向(+1/-1), 圈数, 转速rpm, 加速度rpm/s`

### 加减速

模块内部每 10ms 按 `accel` 把转速从最低速斜坡加到目标转速，
避免 42 电机一启动就丢步。32 细分、30rpm 时，120rpm/s 的加速度约 0.25 秒加到目标。

### 上电演示

`main.c` 里调用 `StepperDrive_DemoStart()`，效果：**正转 1 圈 → 停 0.5 秒 → 反转 1 圈 → 停**。

参数在 `app_stepper_drive.h`：

| 宏 | 默认 | 说明 |
|---|---|---|
| `DRIVE_DEMO_RPM` | 30 | 转速，30 = 2 秒一圈 |
| `DRIVE_DEMO_ACCEL` | 120 | 加速度 rpm/s |
| `DRIVE_DEMO_REVS` | 1 | 每段圈数 |
| `DRIVE_DEMO_PAUSE_MS` | 500 | 两段之间的停顿 |
| `DRIVE_DEMO_SPIN` | 0 | 改 1 = 上电后一直转 |
| `DRIVE_PPR` | 3200 | 脉冲/圈，要与拨码一致 |

### 与串口命令的关系

`AppStepper_*`（串口 `M1/V1` 命令）和本模块共用同一个 TIM8。
**不要同时使用**：上电演示会自动结束，之后再用串口命令，或反之。

## 3. 拨码开关（手册表 2-2）

拨码 123 = 细分（**导通=1，断开=0**；内部有上拉，断开时 MS 脚实际为高）：

| MS1 | MS2 | MS3 | 细分 | 脉冲/圈(1.8°) |
|---|---|---|---|---|
| 1 | 1 | 1 | 不细分 | 200 |
| 0 | 1 | 1 | 2 | 400 |
| 0 | 1 | 0 | 4 | 800 |
| 1 | 0 | 0 | 8 | 1600 |
| **0** | **0** | **0** | **16(默认)** | **3200** |
| 1 | 0 | 1 | 32 | 6400 |

代码宏 `D36_MICROSTEP` 必须与拨码一致。拨码 456 设置电流（见手册电流表）。

## 4. 串口指令（USART3 115200）

| 指令 | 含义 |
|---|---|
| `H` | 帮助 |
| `S` | 状态（EN/busy/剩余步数） |
| `M1 <steps> [freq]` | 轴1相对运动 |
| `M2 <steps> [freq]` | 轴2相对运动 |
| `B <s1> <s2> [freq]` | 双轴 |
| `V1 +1/-1/0 [freq]` | 轴1连续/停 |
| `V2 +1/-1/0 [freq]` | 轴2连续/停 |
| `E1 1/0` `E2 1/0` `E 1/0` | 使能/休眠 |
| `1`/`2`/`0` | 双轴正转/反转/停 |
| `X`/`STOP` | 全停 |

示例：

```text
E 1
M1 3200 800
B 800 -800 1000
E1 0
```

## 6. 接线检查清单（手册注意事项）

1. 控制接口丝印在板子**背面**，别接反电源  
2. EN 必须为高，否则休眠不转  
3. ST 必须是脉冲（有上升沿），常高/常低都不会转  
4. 细分拨码与 `D36_MICROSTEP` 一致  
5. 共地；VIN 接 12V；首次用小电流档
