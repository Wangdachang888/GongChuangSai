# 底盘调试 + 夹取整理版

这是从原工程复制出来的独立 Keil 工程。原工程没有被修改；本目录内的 `main.c` 和 `app_pick_control.c` 是整理版专用入口与按键控制。

## 保留内容

- 四轮麦克纳姆底盘：速度模式、车体速度模式、位置模式、全向移动、原地旋转、编码器反馈、IMU 航向融合和 PID。
- 基础调试：USART3 @ 115200 的 D36 步进命令、步进状态查询、使能/停止、单轴/双轴移动和连续转动。
- 夹取两个动作：PE0 短按启动正向夹取/放置，PE0 长按（>=700 ms）启动反向夹取/释放。
- ICM-20948 姿态与导航底层、四路电机闭环、D36 双轴 STEP/DIR、双舵机平滑运动。

## 已移除

比赛视觉识别、二维码路线、比赛状态机、任务规划、方形轨迹、VOFA 专用调参、独立步进测试界面、历史备份和日志查看器均未放入本目录。

## USART3 调试命令

发送 `H` 查看帮助；常用命令：

```text
M1 <steps> [freq]   单轴1移动
M2 <steps> [freq]   单轴2移动
B <s1> <s2> [freq] 双轴移动
V1 <+1|-1|0> [freq] 单轴1连续转/停
V2 <+1|-1|0> [freq] 单轴2连续转/停
E 1|0               全部使能/失能
S                   查询状态
X                   全部停止
```

底盘运动接口在 `Hardware/mecanum_chassis.h` 中，调试时可在 Keil Watch 中观察全局 `chassis` 和四个 `Motor_t` 实例，或在调试器中调用现有运动 API。

工程文件：`MDK-ARM/GongChuangSai_Clean.uvprojx`。
